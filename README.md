# Mubashar Hussain — Portfolio & Vercel AI SDK Agent

Full Stack Development & AI Integration portfolio featuring an interactive 3D landing page and an autonomous AI Agent powered by the Vercel AI SDK.

## 🌟 Key Features

- **Autonomous AI Agent** — Built with Vercel AI SDK (`ai`, `@ai-sdk/google`, `zod`)
- **Tool Calling** — `getProjects()`, `checkAvailability()`, `getSkills()`, `calculateEstimate()`
- **Streaming UX** — Real-time streaming responses with typing animations
- **Zero-Config Fallback** — Works even before an API key is set

## 🛠 Tech Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS 4, Lucide Icons, Motion
- **Backend:** Vercel Serverless Functions (`/api/chat.ts`)
